# v0.3 — 전체 텍스트 1차 검수 수정본

**Assets에서 `TerribleLizards_Korean_v0.3.zip`을 받으세요.**

게임 종료 → 압축 해제 → `terrible_lizards` 폴더를 게임 `Content` 폴더에 복사·덮어쓰기 → Japanese 선택 → 자막 켜기·저장 순서로 적용합니다. ZIP에는 폴더 아래 패치 PAK 파일 하나만 들어 있습니다.

## 변경 사항

- 전체 2,606개 문자열 원문 대조 및 56개 수정.
- 전화 대사, 암호 읽기, 조작 안내, 문서 제목, 공룡 용어와 어색한 직역 개선.
- 누락된 줄바꿈 복구와 근거 없이 확장한 고유명사 정리.
- `左 Shift` → `왼쪽 Shift` 수정. 엔진의 조작 키·조합 표식 362개 별도 처리.
- PAK 재추출 비교, 빈 값·태그·암호·줄바꿈·글꼴·ZIP 구조 검사 통과.
- 메인 메뉴·접근성·언어 선택·자막 옵션의 한국어 표시 확인.
- 다운로드를 Releases로 전환.

Xbox PC / WinGDK, 게임 프로젝트 버전 `v0.3.24+2233f6e` 기준입니다. 전체 챕터 실플레이와 모든 자막의 문맥·타이밍·잘림, 새 키 이름의 모든 화면 표시는 추가 확인 대상인 베타입니다.
