# v0.5 — 3차 집중 검수 수정본

게임 종료 → 압축 해제 → `terrible_lizards` 폴더를 게임 `Content` 폴더에 복사·덮어쓰기 → Japanese 선택 → 자막 켜기·저장 순서로 적용합니다. ZIP에는 패치 폴더 아래 PAK 파일 하나만 들어 있습니다.

## 변경 사항

- 수량·부정·조건·조작 안내 및 관련 대사·문서 589개 집중 재대조.
- v0.4 대비 16개 문자열 수정, 연결된 키 16개에 반영.
- ‘한 마리보다 많다’의 의미를 ‘두 마리 이상’으로 수정하고 시설 퇴거 규정과 길 안내를 명확히 함.
- 사물 이동 제목, 가지에 매달려 흔들기와 조명 연구 용어 정리.
- 원문에 없는 ‘아저씨’ 호칭 제거와 반복 부정 대사의 누락 복원.
- ‘진흙투성이에요’ 표기와 일기·문서의 직역 수정.
- 한국어 글꼴과 `왼쪽 Shift` 등 기존 조작 키 수정 유지.

전체 2,606개 문자열과 공용 키 이름 362개의 빈 값·태그·버튼 표식·암호·CR/LF 줄바꿈·글꼴·원문 해시·참조 횟수를 검사했습니다. PAK 내부 9개 파일 재추출 비교와 ZIP 무결성 검사도 통과했습니다.

Xbox PC / WinGDK, 게임 프로젝트 버전 `v0.3.24+2233f6e` 기준입니다. **이번 검수는 중점 문구의 3차 집중 검수이며, v0.5의 실제 게임 실행과 전체 챕터 검증은 진행하지 않은 베타입니다.** 모든 자막의 장면별 문맥·타이밍·잘림은 추가 확인 대상입니다.

업데이트는 같은 파일 덮어쓰기, 제거는 해당 PAK 파일 하나 삭제로 진행합니다.
