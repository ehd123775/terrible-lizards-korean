# v0.6 — 전체 텍스트 4차 검수 수정본

게임 종료 → 압축 해제 → `terrible_lizards` 폴더를 게임 `Content` 폴더에 복사·덮어쓰기 → Japanese 선택 → 자막 켜기·저장 순서로 적용합니다. ZIP에는 패치 폴더 아래 PAK 파일 하나만 들어 있습니다.

## 변경 사항

- 한국어 문구 2,606개 전체 정독, 의심 문구 52개 영어 원문 재대조.
- v0.5 대비 50개 문자열 수정, 연결된 키 50개에 반영.
- 정황 추론과 강조를 나타내는 관용어, 닭의 개체 수, 비교 강조 방향 수정.
- 반복 부정 대사의 누락과 선물·소속감 대사의 연결 개선.
- 마지막 연락에 대비한 구조 약속과 인형의 받침대 배치 전 소실 조건 명확화.
- DJ 상태 확인 목표, 극장 개찰구 안내와 접근성 설명 수정.
- 교대 근무·연구 보고서·편지·상품 홍보의 어색한 표현 정리.
- 한국어 글꼴과 `왼쪽 Shift` 등 기존 조작 키 수정 유지.

전체 2,606개 문자열과 공용 키 이름 362개의 빈 값·태그·버튼 표식·암호·CR/LF 줄바꿈·글꼴·원문 해시·참조 횟수를 검사했습니다. 한자 잔존 검사, PAK 내부 9개 파일 재추출 비교와 ZIP 무결성 검사도 통과했습니다.

Xbox PC / WinGDK, 게임 프로젝트 버전 `v0.3.24+2233f6e` 기준입니다. **전체 한국어 정독 후 의심 문구를 원문 대조한 4차 검수 수정본이며, v0.6의 실제 게임 실행과 전체 챕터 검증은 진행하지 않은 베타입니다.** 모든 자막의 장면별 문맥·타이밍·잘림은 추가 확인 대상입니다.

업데이트는 같은 파일 덮어쓰기, 제거는 해당 PAK 파일 하나 삭제로 진행합니다.
