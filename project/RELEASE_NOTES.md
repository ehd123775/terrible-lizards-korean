# v0.7 — 전체 텍스트 5차 검수 수정본

게임 종료 → 압축 해제 → `terrible_lizards` 폴더를 게임 `Content` 폴더에 복사·덮어쓰기 → Japanese 선택 → 자막 켜기·저장 순서로 적용합니다. ZIP에는 패치 폴더 아래 PAK 파일 하나만 들어 있습니다.

## 변경 사항

- 전체 2,606개 문구의 영어 원문·한국어 번역 일대일 대조.
- v0.6 대비 18개 문자열 수정, 연결된 키 18개에 반영.
- 두 자막에 걸친 조건과 결론의 연결을 명확히 함.
- 강한 크기·지능 비교, 상대에게 확인하는 질문과 도움 대상의 누락 복원.
- 반복 부정 및 yeah 반복 대사 4곳의 누락 수정.
- 빛의 스펙트럼, 무급 휴직, 중개인 묘사와 관용어·문서 문장 정리.
- 한국어 글꼴과 `왼쪽 Shift` 등 기존 조작 키 수정 유지.

전체 2,606개 문자열과 공용 키 이름 362개의 빈 값·태그·버튼 표식·암호·CR/LF 줄바꿈·글꼴·원문 해시·참조 횟수를 검사했습니다. 한자 잔존 검사, PAK 내부 9개 파일 재추출 비교와 ZIP 무결성 검사도 통과했습니다.

Xbox PC / WinGDK, 게임 프로젝트 버전 `v0.3.24+2233f6e` 기준입니다. **전체 문구를 영한 대조한 5차 검수 수정본이며, v0.7의 실제 게임 실행과 전체 챕터 검증은 진행하지 않은 베타입니다.** 모든 자막의 장면별 문맥·타이밍·잘림은 추가 확인 대상입니다.

업데이트는 같은 파일 덮어쓰기, 제거는 해당 PAK 파일 하나 삭제로 진행합니다.
