## 범위와 방법

연결된 문장의 조건·결론, 부정과 비교의 강도, 상대에게 확인하는 질문, 반복 대사의 누락을 확인했습니다. 반복 부정은 뒤에 다른 문장이 붙는 경우까지 추가로 모아 대조했습니다. 조작 키 362개는 기존 번역을 유지하며 리소스 구조·글꼴·일본어 잔존 검사를 다시 진행했습니다.

18개 문자열을 수정해 연결된 키 18개에 반영했습니다. 검수 대상 전체 ID는 [review_round5.json](review_round5.json)에, 원문·수정 전후·이유는 [review_changes.json](review_changes.json)에 기록했습니다. 스토리 스포일러가 있습니다.

## 파일 검사

- 2,787개 키·원문 해시·인덱스 구역 및 참조 횟수 보존.
- 전체 2,606개 문자열의 빈 값·손상 문자·태그·버튼 표식·CR/LF 검사 통과.
- 0180·0451·1677·1903 암호와 BUTTON·CODE 동적 표식 유지.
- 앞선 34곳의 숫자 표기 차이는 그대로이며 v0.6 대비 새 불일치 없음.
- 기존 단독 반복 부정 검사와 이번에 수정한 반복 대사 4곳의 횟수 검사 통과.
- 게임 문구의 한자 없음. 원문의 이모티콘 `¯\_(ツ)_/¯` 한 곳은 유지.
- 공용 키 이름 362개 유지. LeftShift는 왼쪽 Shift이며 키 이름의 일본어 가나·한자 없음.
- 번역과 공용 키에서 사용하는 모든 공백 외 문자의 글꼴 포함 확인.
- PAK 내부 9개 파일 재추출 비교 통과. v0.6 대비 게임 번역 리소스만 변경.
- ZIP에는 `terrible_lizards/Content/Paks/zzz_TerribleLizards_Korean_P.pak` 파일 하나만 포함. CRC·SHA-256 검사 통과.
