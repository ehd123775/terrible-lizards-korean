- 2,787개 키·원문 해시·인덱스 구역 원본과 바이트 단위 일치.

## 실제 화면과 한계

이전 v0.3에서 메인 메뉴·접근성·언어 선택·자막 옵션의 한국어 표시를 확인했습니다. 이번 v0.4의 게임 실행은 진행하지 않았습니다. 전체 챕터 진행, 자막 타이밍, 화면 잘림과 장면별 말투는 추가 확인 대상입니다. 사용자 요청대로 게임 조작은 진행하지 않았습니다.

2차 검수는 전체 번역 파일 대조이며 전체 게임 플레이 검증을 뜻하지 않습니다.
