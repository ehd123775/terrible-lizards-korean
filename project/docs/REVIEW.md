# v0.5 3차 집중 검수 보고서

2026년 10월 31일 기준입니다. 비교 기준은 v0.4입니다.

## 범위와 방법

전체 2,606개 문자열은 앞선 2차 영한 대조를 마친 상태입니다. 이번에는 수량·부정·조건·조작 안내와 관련 대사·문서 등 589개 문자열을 골라 집중 대조했습니다. 16개 문자열을 수정해 연결된 키 16개에 반영했습니다. 전체 문자열의 기계적 파일 검사도 다시 진행했습니다.

검수 대상 ID는 [review_round3.json](review_round3.json)에 기록되어 있습니다. 이번 검수는 2,606개 전체의 3차 정독이나 게임 내 재생 순서 검증을 뜻하지 않습니다. 모호한 문구 일부는 원본 일본어 번역도 참고했지만 최종 의미는 영어 원문을 기준으로 삼았습니다.

## 파일 검사

- 2,787개 키·원문 해시·인덱스 구역 및 원문 참조 횟수 보존.
- 전체 2,606개 문자열의 빈 값·손상 문자·태그·버튼 표식·CR/LF 검사 통과.
- 0180·0451·1677·1903 암호와 BUTTON·CODE 동적 표식 유지.
- 앞선 34곳의 숫자 표기 차이는 그대로이며 v0.4 대비 새 불일치 없음.
- 공용 키 이름 362개 유지, LeftShift가 왼쪽 Shift로 들어 있음. 일본어 가나·한자 없음.
- 번역과 공용 키에서 사용하는 모든 공백 외 문자의 글꼴 포함 확인.
- PAK 내부 9개 파일 재추출 비교 통과. v0.4 대비 게임 번역 리소스만 변경.
- ZIP에는 `terrible_lizards/Content/Paks/zzz_TerribleLizards_Korean_P.pak` 파일 하나만 포함. CRC·SHA-256 검사 통과.
