# v0.6 전체 텍스트 4차 검수 보고서

2026년 10월 31일 기준입니다. 비교 기준은 v0.5입니다.

## 범위와 방법

게임 텍스트의 중복 제외 2,606개 한국어 문구를 처음부터 끝까지 정독했습니다. 메뉴·설정·튜토리얼·목표·수집품·대사·편지·일지·연구 및 군사 문서·제작진 안내가 포함됩니다. 의심 문구 52개는 영어 원문을 다시 대조했고, 모호한 일부는 원본 일본어 번역도 참고했습니다. 조작 키 이름·조합 표식 362개도 다시 살폈습니다.

50개 문자열을 수정해 연결된 키 50개에 반영했습니다. 이번 방법은 **전체 한국어 정독 후 의심 문구 원문 대조**입니다. 모든 영문을 다시 정독한 검수나 게임 내 재생 순서·상황 검증을 뜻하지 않습니다. 전체 영한 대조는 앞선 2차 검수에서 진행했습니다.

검수 범위와 원문 재대조 ID는 [review_round4.json](review_round4.json)에, 원문·수정 전후·이유는 [review_changes.json](review_changes.json)에 기록했습니다. 스토리 스포일러가 있습니다.

## 파일 검사

- 2,787개 키·원문 해시·인덱스 구역 및 원문 참조 횟수 보존.
- 전체 2,606개 문자열의 빈 값·손상 문자·태그·버튼 표식·CR/LF 검사 통과.
- 0180·0451·1677·1903 암호와 BUTTON·CODE 동적 표식 유지.
- 앞선 34곳의 숫자 표기 차이는 그대로이며 v0.5 대비 새 불일치 없음.

- 한국어 게임 문구에 한자 없음. 원문의 이모티콘 `¯\_(ツ)_/¯` 한 곳은 유지.
- 공용 키 이름 362개 유지, LeftShift는 왼쪽 Shift. 키 이름의 일본어 가나·한자 없음.
- 번역과 공용 키에서 사용하는 모든 공백 외 문자의 글꼴 포함 확인.
- PAK 내부 9개 파일 재추출 비교 통과. v0.5 대비 게임 번역 리소스만 변경.
- ZIP에는 `terrible_lizards/Content/Paks/zzz_TerribleLizards_Korean_P.pak` 파일 하나만 포함. CRC·SHA-256 검사 통과.
