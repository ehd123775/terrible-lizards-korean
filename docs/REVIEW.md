# v0.3 검수 보고서

2026년 10월 31일 기준입니다.

## 원문 대조

2,787개 키에 연결되는 중복 제외 2,606개 문자열을 전체 대조했습니다. 대사·문서·메뉴·목표·아이템·튜토리얼의 의미, 자연스러운 표현과 용어를 살피고 56개 문자열을 수정했습니다. 18개는 숫자·기호·브랜드·기술명으로 유지했습니다.

수정 유형: 전화 대사의 동사 선택, 암호 0180 읽기, 문서 제목, 조작 설명, 신체·화석 용어, 어색한 직역, 원문 약칭의 불확실한 확장, 줄바꿈 누락.

상태 `text_reviewed`는 원문 대조를 마쳤다는 뜻이며, 모든 장면의 화자·말투·타이밍까지 검증했다는 뜻은 아닙니다.

## 조작 키 수정

사용자 화면에서 보고된 `左 Shift`는 일본어 문화권에서 엔진 공용 InputKeys를 읽어 발생했습니다. 게임 대사 리소스와 분리된 엔진 키 이름 및 키 조합 표식 362개를 별도로 묶었습니다. 왼쪽·오른쪽 Shift/Ctrl/Alt, 방향키, 마우스, 주요 컨트롤러 버튼은 한국어로, 나머지 기기·기술 키 이름은 영어로 표시합니다.

이 추가 리소스에는 일본어 가나·한자가 없는 것을 검사했습니다. 네임스페이스·키 해시·원문 해시는 원본에서 보존하고 새 인덱스와 참조 횟수를 검사했습니다. 패키지 내부에서 LeftShift가 왼쪽 Shift로 읽히는 것을 확인했습니다. 수정 후 실제 튜토리얼 화면 검증은 사용자 확인 대상입니다.

## 파일 검사

- 게임 언어 리소스의 키·원문 해시·인덱스 구역이 원본과 바이트 단위 일치.
- 문자열 참조 횟수 및 2,787개 키 대응 확인.
- 빈 값·손상된 문자·태그·치환 표식·CR/LF 줄바꿈 검사 통과.
- 날짜의 월 이름과 영어 숫자 등 표기가 달라진 34곳 별도 대조.
- 게임 번역 및 추가 키 이름의 사용 문자에 대한 글꼴 포함 검사.
- PAK 내부 9개 파일 재추출 비교 통과.
- ZIP에 지정된 패치 PAK 경로 하나만 포함하도록 검사.

[qa_report.json](qa_report.json)에서 검사 결과를 확인할 수 있습니다. [review_changes.json](review_changes.json)은 원문과 수정 전후 문장을 포함하며 스토리 스포일러가 있습니다.

## 실제 화면과 한계

메인 메뉴, 접근성 설정, 언어 선택, 자막 옵션에서 한국어 표시를 확인했습니다. 전체 챕터 진행, 모든 컷신 타이밍과 문서 잘림, 장면별 대사 문맥은 추가 확인 대상입니다. 사용자 요청에 따라 더 이상의 게임 조작은 진행하지 않았습니다.
